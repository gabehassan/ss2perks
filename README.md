# SS2 Perk Calculator

Build planner for [Sausage Survivors 2](https://sbox.game) (s&box). Pick perks and
curses, see your stats update live, and check DPS and boss time-to-kill before you
commit to a run.

**[ss2perks.vercel.app](https://ss2perks.vercel.app)**

441 perks and curses with the game's own stat formulas — Set, Add and Mult
modifiers resolved in the same order the game resolves them. Builds share as a URL.

```bash
pnpm install
pnpm dev
```

Perk data lives in `data/perks.json`. Not affiliated with the game or its developers.
